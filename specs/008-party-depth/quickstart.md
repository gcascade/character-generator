# Quickstart: Party Depth

## Automated

```bash
npm run test:run && npm run typecheck && npm run lint
npm run build && npm run build-storybook
```

## Browser

1. Generate parties of 4 several times: some have ties, some none; ties name two members and read well in FR/EN.
2. Each card has a role; open its menu, pick one, then "Random"; keep the member and regenerate: role kept.
3. Balance panel shows five areas with text levels; a party with no cleric shows the healing hint.
4. Adventure hook shown; reroll only the hook.
5. Save, reload, share and open the link: ties, roles and hook unchanged. An old `p1` link still opens.
6. French, dark mode, phone: no horizontal scroll; axe clean.
