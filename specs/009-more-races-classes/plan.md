# Implementation Plan: More Races and Classes

**Branch**: `claude/cool-keller-vpldvo` | **Date**: 2026-11-20 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/009-more-races-classes/spec.md`

## Summary

Append 5 races (Halfling, Gnome, Half-elf, Dark elf, Ashborn) and 5 classes (Ranger, Paladin, Bard, Druid,
Barbarian) to the `as const` enums (append-only, so share links keep their meaning), then fill every place that is
keyed by race or class: name lists, lifespans, origin and training fragments with their texts in both languages,
gendered labels, colours (contrast-tested), icons, balance points and role weights. Portraits: a new `RaceEmblem`
vector illustration in the class colour replaces the generic default image when a combination has no file; image
paths use slugs (`dark-elf`, `half-elf`). A `docs/portraits.md` guide lists the missing files.

## Technical Context

**Language/Version**: TypeScript 6 (strict), React 19

**Primary Dependencies**: MUI 9 (+ icons), zod 4; no new dependency

**Storage**: unchanged (new enum values are valid in stored data and links)

**Testing**: existing content tests extended automatically (they iterate the enums); new tests for distribution
(SC-001), portrait fallback (SC-004), old link decoding (SC-005), palette contrast (SC-003)

**Target Platform**: evergreen browsers, static GitHub Pages site

**Project Type**: single-page web application, client-side only

**Constraints**: enums append-only; French agreement and neutral phrasing; no external art assets

**Scale/Scope**: ~800 names, 20 origins and 20 trainings per language, 10 labels × 2 languages, 10 colours × 2
modes, 10 icons, 5 emblems
