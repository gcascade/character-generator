# Quickstart: More Races and Classes

```bash
npm run test:run && npm run typecheck && npm run lint && npm run build && npm run build-storybook
node scripts/missing-portraits.mjs
```

Browser: generate until each new race and class shows up; check names, ages, stories (EN/FR, each gender), badges and
icons in both modes, emblem portraits; lock a new race; generate a party of 6 with new classes (roles, balance);
share a dark elf bard and reopen; open an old share link.
